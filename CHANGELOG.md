# Changelog

## 1.2.0

- Added professional display names for bundled models.
- Kept stable internal model IDs for backward compatibility.
- Kept Editto Precision v2 as the conservative default.
- Included selectable legacy models and the experimental Editto Neural v3 model.
- Added local manual labeling and personal microphone/model training documentation.
- Packaged FFmpeg and CPU inference dependencies in the Windows installer.
